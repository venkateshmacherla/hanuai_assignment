HanuAi Data Analytics Assessment

Overview

This project focuses on web scraping, sentiment analysis, exploratory data analysis (EDA), and text mining using Python.

Task 1: Web Scraping and Sentiment Analysis

- Scrape publicly accessible product reviews from Best Buy Canada, subject to website policies.
- Extract review title, text, date, rating, reviewer name, and source.
- Apply sentiment analysis to classify reviews as Positive, Neutral, or Negative.
- Export processed review data to CSV.

Task 2: EDA and Text Mining

- Analyze data types, missing values, and duplicate records.
- Perform statistical analysis and create visualizations.
- Extract meaningful tags from text.
- Categorize issues and identify recurring patterns.
- Apply clustering to group similar issues.
- Provide actionable business recommendations.

Technologies Used

- Python
- Selenium
- Beautiful Soup
- Pandas
- NLTK
- spaCy
- Scikit-learn
- Matplotlib
- Seaborn

Project Structure

- "data/" — Input datasets and review data
- "notebooks/" — Task 1 and Task 2 notebooks
- "requirements.txt" — Python dependencies

Setup

Install the required packages:

pip install -r requirements.txt

Install the spaCy English language model:

python -m spacy download en_core_web_sm

Open the notebooks in VS Code or Jupyter Notebook and run the cells in order. Ensure the required datasets are available before running the analysis.

Expected Deliverables

- Python notebooks for both tasks
- CSV/Excel analysis outputs
- Sentiment classifications and extracted text tags
- EDA visualizations
- Reports containing findings and recommendations

Responsible Data Collection

Use only permitted publicly accessible information. Respect website terms, access restrictions, and rate limits. Do not bypass CAPTCHAs or other access controls.
